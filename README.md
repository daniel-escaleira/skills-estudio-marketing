# Skills do Estúdio de Marketing e Redes Sociais

Painel de consulta: 175 skills do Claude Code organizadas por etapa de trabalho, com o que cada uma faz, o comando para chamar e um exemplo de pedido. Em português.

Página: https://daniel-escaleira.github.io/skills-estudio-marketing/

## Origem das skills

O painel descreve skills de três repositórios de código aberto (licença MIT) e de um orquestrador próprio. As descrições foram resumidas e traduzidas; o método completo está no repositório de cada autor.

- [social-media-skills/skills](https://github.com/social-media-skills/skills) — Frank Heijdenrijk
- [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) — Corey Haines
- [ScrapeCreators/social-media-research-skills](https://github.com/ScrapeCreators/social-media-research-skills) — ScrapeCreators

Este repositório contém só a página do painel, não as skills.
